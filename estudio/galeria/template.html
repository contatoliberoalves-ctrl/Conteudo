Estúdio de Vídeo

Cada modelo é um jeito pronto de editar. Mande o vídeo bruto (ou um roteiro) e diga qual modelo usar: o Claude transcreve, corta, enquadra, legenda, mixa e entrega. Toque no vídeo para ouvir. As amostras de vídeo com gente usam um vídeo seu; as de motion foram feitas do zero.

Comandos no repositório: python3 estudio/ev.py. Estilos de cada perfil em estudio/estilos/; cada correção que você pedir é gravada no estilo para o próximo vídeo já sair certo.
