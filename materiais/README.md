# Materiais-base do autor

Conteúdo do @constitucionalgabaritado usado como fonte dos posts. **Os arquivos não ficam neste repositório** (ele é público e o material é autoral): estão com o dono. Numa sessão nova, peça o arquivo ou o link do Google Drive/Docs antes de escrever um post a partir deles. Regra de todos os moldes: usar o texto do autor literalmente, só distribuindo entre os slides.
