# PratFlix para Cartórios · landing page

Página da frente de comunicação, conteúdo e capacitação para cartórios (briefing de 9/11/2026).
Publicada em https://claude.ai/artifact/CQGmNAkmCMECzp29U4vQXb (publique `index.html` com `root: site/pratflix-cartorios` e os `img/*.webp` no `files`).

- `img/`: recortes de trabalhos reais, tirados das galerias publicadas (cartório, Entre Notas e Registros, ANOREG/PE,
  PratFlix, Renato, Eduarda) e das cenas do `moldes/anoreg-conecta` (`node render.mjs png`).
- Contatos: objeto `CONTATO` no topo do `<script>`. Com `whatsapp` preenchido, o montador abre o WhatsApp com o pedido
  escrito; sem ele, o visitante copia o resumo e manda pelo direct do Instagram. A página nunca diz que o pedido foi enviado.
- Valores dos planos: referências do portfólio da Indubio (jun/2025), sempre marcadas como referência.
