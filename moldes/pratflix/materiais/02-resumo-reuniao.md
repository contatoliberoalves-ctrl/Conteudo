# Anotação interna e resumo para o cliente

Depois de uma reunião existem dois textos diferentes. Misturar os dois é a origem de boa parte dos mal-entendidos.

| | Registro interno | Resumo enviado ao cliente |
|---|---|---|
| Para quem | Você e a equipe | O cliente (e só ele) |
| Objetivo | Não perder nada e saber o que fazer | Confirmar o que foi entendido e combinado |
| Tamanho | O necessário, pode ser longo | Curto, legível no celular |
| Conteúdo | Fatos, hipóteses, dúvidas, impressões, estratégia | Fatos confirmados, decisões, pendências, próximos passos |
| Linguagem | Técnica, abreviada | Simples, sem jargão |

## O que não vai automaticamente para o resumo do cliente

- **Hipóteses jurídicas ainda não verificadas.** "Talvez caiba indenização" vira expectativa. Se ainda é hipótese, fica no registro interno.
- **Impressões sobre pessoas.** "A outra parte parece desorganizada" não ajuda o cliente e pode circular.
- **Informações de terceiros** que chegaram por outra fonte e não foram confirmadas.
- **Estratégia em construção.** Alternativas ainda em estudo aparecem como "estou analisando", sem detalhar o plano.
- **Comentários sobre honorários de outros profissionais** ou sobre a atuação de colegas.

::: quadro Regra prática
Antes de copiar uma frase do registro interno para o resumo, pergunte: o cliente precisa disso para decidir ou agir? Se não precisa, deixe no registro interno.
:::

## Modelo B: mensagem externa

::: exemplo Estrutura em cinco partes
1. **Abertura:** agradecimento e referência à reunião (data).
2. **O que entendi:** duas a quatro frases com os fatos confirmados.
3. **O que decidimos:** decisões, em frases curtas.
4. **O que fica com cada um:** pendências do cliente e do advogado, com data.
5. **Limite do que foi combinado:** o que está e o que não está incluído neste momento.
:::

# Matriz de ações

Toda ação precisa de verbo concreto, responsável com nome, data combinada e critério para saber que terminou.

{.grade}
| Ação (verbo + objeto) | Responsável | Depende de | Data combinada | Pronto quando | Status |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

**Status:** a fazer · em andamento · aguardando cliente · aguardando terceiro · concluído

::: atencao Data combinada não é prazo jurídico
A data da matriz é um combinado de trabalho. Se a ação tiver prazo processual ou legal, ele precisa ser conferido na norma e no processo e registrado separadamente, com a fonte da conferência. Nunca use a data interna como se fosse o prazo.
:::

# Exemplo preenchido: análise de contrato de locação

Caso fictício. Lúcia Prado é dona de uma pequena loja e vai alugar uma sala comercial. Recebeu a minuta do contrato do corretor e quer saber se pode assinar. Na reunião, ficou combinada apenas uma análise delimitada. Uma eventual negociação com o locador não foi contratada.

## Registro interno

| Campo | Preenchimento |
|---|---|
| Caso | 2026-044 · Locação comercial Prado |
| Data, duração e canal | 05/10/2026, 45 min, presencial |
| Participantes | Lúcia Prado (cliente); advogado responsável |
| Objetivo da reunião | Entender o negócio e definir o que será analisado |
| Documentos examinados | Minuta do contrato (12 páginas), sem os anexos citados nas cláusulas 4 e 9 |
| Fatos a confirmar | Prazo de 36 meses e carência de 3 meses (relatado; a minuta fala em 2 meses). Existência de vistoria de entrada |
| Decisões | Análise escrita da minuta com pontos de atenção. Sem negociação com o locador nesta etapa |
| Alternativas em análise | Pedir ao locador a inclusão da carência de 3 meses, se a cliente decidir negociar depois |
| Pendências | Lúcia envia anexos 4 (vistoria) e 9 (regulamento do condomínio) até 08/10. Advogado entrega análise até 15/10 |
| Observações internas | Cliente tem pressa: corretor pediu assinatura até 20/10. Explicar que a análise depende dos anexos |

## Mensagem enviada

::: exemplo Resumo para a cliente
Olá, Lúcia. Obrigado pela reunião de hoje (05/10).

Entendi que você vai alugar a sala da Rua das Acácias para a loja e recebeu a minuta do contrato do corretor. O corretor pediu a assinatura até 20/10.

Combinamos que eu faço uma análise escrita da minuta, apontando as cláusulas que merecem atenção antes da assinatura.

Para isso, preciso dos anexos 4 (vistoria) e 9 (regulamento do condomínio), que estão citados no contrato mas não vieram. Você consegue me mandar até quinta (08/10)? Com eles, te entrego a análise até 15/10.

Um ponto para conferirmos: você mencionou 3 meses de carência, mas a minuta fala em 2. Vale confirmar com o corretor o que foi prometido.

Neste momento, o combinado é só a análise. Se depois você quiser que eu converse com o locador para pedir mudanças, a gente combina essa etapa à parte.
:::

## Matriz de ações do caso

| Ação | Responsável | Depende de | Data | Pronto quando | Status |
|---|---|---|---|---|---|
| Enviar anexos 4 e 9 | Lúcia | Corretor | 08/10 | Arquivos recebidos e legíveis | Aguardando cliente |
| Confirmar carência com o corretor | Lúcia | Corretor | 08/10 | Resposta por escrito | Aguardando cliente |
| Analisar minuta e anexos | Advogado | Anexos | 14/10 | Análise revisada | A fazer |
| Enviar análise escrita | Advogado | Análise pronta | 15/10 | E-mail enviado com PDF | A fazer |

# Registros que não funcionam

Cada registro abaixo aparece em anotações reais. A versão melhor permite saber quem faz o quê e quando acaba.

::: ruim "Ver isso"
Não diz o que ver, quem vê, nem quando.
:::
::: melhor Versão melhor
"Ler a cláusula 7 (multa) e anotar se o valor é proporcional ao prazo restante. Advogado, até 14/10."
:::

::: ruim "Urgente"
Urgente sem data vira tudo urgente ao mesmo tempo.
:::
::: melhor Versão melhor
"Enviar análise até 15/10, porque o corretor pediu assinatura até 20/10."
:::

::: ruim "Cliente resolver"
Não diz o que o cliente precisa fazer nem se ele sabe disso.
:::
::: melhor Versão melhor
"Lúcia confirma com o corretor, por escrito, se a carência é de 2 ou 3 meses. Pedido feito na mensagem de 05/10. Até 08/10."
:::

::: ruim "Ganhar ação"
É um desejo, não uma tarefa. E sugere promessa de resultado.
:::
::: melhor Versão melhor
"Montar a lista de documentos que comprovam a entrega do serviço. Advogado, até 20/10."
:::

::: ruim "Aguardar"
Aguardar o quê, de quem, até quando? Sem isso, a tarefa fica parada para sempre.
:::
::: melhor Versão melhor
"Aguardar resposta do locador sobre a carência até 12/10. Se não vier, lembrar a cliente em 13/10."
:::

# Mensagens prontas e revisão antes de enviar

## Três mensagens

::: exemplo Resumo após reunião
Olá, [nome]. Obrigado pela conversa de hoje ([data]). Entendi que [fatos em duas frases]. Combinamos que [decisão]. Você fica de [pendência] até [data] e eu de [providência] até [data]. Neste momento, o combinado é [escopo]; [o que ficou de fora] a gente combina à parte, se for o caso. Se algo estiver diferente do que você entendeu, me avise.
:::

::: exemplo Lembrete cordial de documento
Olá, [nome]. Passando para lembrar do [documento] que combinamos para [data]. Com ele eu consigo [o que depende disso]. Se tiver alguma dificuldade para conseguir, me conta que a gente pensa em outra forma.
:::

::: exemplo Pendência que impede avançar
Olá, [nome]. Para seguir com [etapa], ainda preciso de [documento ou informação]. Sem isso, não consigo [o que fica parado] com segurança. Assim que eu receber, retomo e te dou retorno em até [número] dias úteis.
:::

## Protocolo de revisão

- [ ] O destinatário está certo (e só ele)?
- [ ] Os anexos são os certos, na versão certa?
- [ ] Há informação de terceiro que não deveria estar ali?
- [ ] O escopo está claro: o que foi combinado e o que ficou de fora?
- [ ] Alguma frase afirma conclusão jurídica que ainda não foi verificada?
- [ ] Alguma frase pode ser lida como promessa de resultado?
- [ ] O resumo pode ser lido como aceite de um serviço que não foi contratado? Se sim, reescreva.

## Quando o cliente corrige o resumo

Se o cliente responder dizendo que algo está diferente, registre no registro interno: a data da correção, o que mudou e se isso altera alguma decisão ou pendência. Responda confirmando a versão corrigida. Não apague o resumo anterior: o histórico mostra como o entendimento evoluiu.

::: exemplo Resposta a uma correção
Obrigado pela correção, [nome]. Então fica assim: [ponto corrigido]. O restante continua como combinado.
:::

# Exercício: das notas soltas ao plano de ação

Abaixo estão as notas de uma reunião, como foram escritas. Transforme-as em um registro interno, uma matriz de ações e uma mensagem para o cliente.

::: exemplo Notas da reunião (caso fictício)
Rui, 14/10, vídeo. Oficina mecânica. Cliente antigo não pagou 3 serviços, ~R$ 4.200. Tem notas? acha que sim. Fala que mandou áudio cobrando. Quer "processar logo". Ver se tem orçamento assinado. Rui vai procurar. Eu: ver o que dá pra fazer. Falar semana que vem. Ele perguntou quanto custa, disse que mando proposta.
:::

**Sua resposta**

[[caixa 12]]

::: resposta Resposta comentada
**Registro interno (trechos principais).** Fatos a confirmar: três serviços prestados e não pagos, total aproximado de R$ 4.200 (valor relatado); existência de notas fiscais e de orçamentos assinados; cobrança por áudio (data e conteúdo). Decisão: o advogado vai analisar os documentos e enviar proposta. Alternativas em análise: cobrança extrajudicial ou judicial, a depender dos documentos. Observação interna: cliente quer "processar logo"; explicar que a escolha do caminho depende do que existe por escrito.

**Matriz.** "Reunir notas fiscais, orçamentos e o áudio de cobrança · Rui · até 19/10 · pronto quando os arquivos forem recebidos." "Enviar proposta de honorários para análise documental e cobrança · advogado · até 16/10." "Analisar documentos · advogado · depende dos arquivos · até 23/10."

**Mensagem.** "Olá, Rui. Obrigado pela conversa de hoje (14/10). Entendi que um cliente da oficina não pagou três serviços, num total aproximado de R$ 4.200. Para eu avaliar o melhor caminho, preciso das notas fiscais, dos orçamentos assinados e do áudio em que você cobrou. Consegue me mandar até segunda (19/10)? Até sexta (16/10) te envio a proposta de honorários. A decisão sobre cobrar de forma amigável ou entrar com ação a gente toma depois de ver os documentos."

**Por que assim.** "Ver o que dá pra fazer" virou duas tarefas com data. "Processar logo" não entrou como decisão, porque ainda não há base para ela. A proposta foi separada da análise, para que a mensagem não seja lida como aceite do serviço. Outras redações são aceitáveis se mantiverem responsável, data e limite do combinado.
:::
