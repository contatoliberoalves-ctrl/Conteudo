# A revisão em 30 minutos

A revisão semanal é uma sugestão de rotina, não uma regra. O objetivo é olhar para o escritório inteiro uma vez por semana e sair com três prioridades claras e nenhuma tarefa sem dono.

| Tempo | Bloco | O que fazer | Saída esperada |
|---|---|---|---|
| 5 min | Agenda e comunicações | Ver os compromissos da semana seguinte e as comunicações recebidas que ainda não viraram tarefa. | Lista de compromissos e comunicações conferidas |
| 10 min | Casos e tarefas | Passar pelo painel de tarefas (parte 03). Atualizar status e próxima ação de cada caso. | Painel atualizado, sem tarefa sem responsável |
| 5 min | Clientes | Ver quem está sem retorno combinado ou com retorno vencido. | Lista de mensagens a enviar |
| 5 min | Documentos e financeiro | Conferir documentos pendentes e o quadro financeiro (parte 05). | Pendências documentais e cobranças a revisar |
| 5 min | Prioridades | Escolher três prioridades e redistribuir o que não cabe. | Agenda de três prioridades |

::: quadro Se passar de 30 minutos
É sinal de que alguma tarefa precisa de uma reunião própria. Anote o assunto, marque outro horário e siga a revisão. A revisão é para olhar tudo, não para resolver tudo.
:::

## Escritório de uma pessoa e equipe de três

**Uma pessoa:** faça a revisão sozinho, em voz alta se ajudar, com o painel aberto. O bloco "prioridades" é o mais importante: ele protege a semana de você mesmo.

**Equipe de três:** cada pessoa atualiza o próprio pedaço do painel antes da reunião (cinco minutos, no dia anterior). Na reunião, uma pessoa conduz e marca o tempo, outra anota as mudanças no painel. Tarefas trocadas de responsável são ditas em voz alta e confirmadas por quem as recebe.

# Fila de exceções: o que não espera a revisão

Algumas coisas não podem esperar a reunião semanal. Elas vão para uma fila separada, olhada todos os dias.

- [ ] Comunicação processual ou prazo ainda não conferido no sistema oficial
- [ ] Situação de risco imediato para um cliente
- [ ] Compromisso marcado sem responsável definido
- [ ] Cliente com retorno combinado para hoje ou já vencido

::: atencao A revisão semanal não substitui o controle diário de prazos
Prazos processuais são conferidos todos os dias, no sistema do tribunal e nos canais oficiais de comunicação, com registro de quem conferiu. A revisão semanal serve para enxergar o conjunto; o controle de prazos serve para não perder nenhum. São rotinas diferentes.
:::

## Os quatro status

| Status | Quer dizer | O que fazer na revisão |
|---|---|---|
| Em execução | Alguém está trabalhando nisso | Confirmar a data e se ela ainda é realista |
| Aguardando cliente | Depende de documento ou decisão do cliente | Ver há quanto tempo; mandar lembrete se passou da data |
| Aguardando terceiro | Depende de órgão, outra parte, cartório, perito | Registrar o último contato e quando cobrar de novo |
| Concluído | Terminou e o critério de conclusão foi atingido | Arquivar e registrar a comunicação ao cliente |

::: quadro A coluna que mais revela problemas
"Última atualização". Uma tarefa em execução sem atualização há três semanas provavelmente está parada. Pergunte por quê.
:::

# Priorização sem fórmula mágica

Não existe pontuação que decida sozinha. A priorização usa quatro perguntas, nessa ordem:

1. **Risco:** se isso não for feito esta semana, alguém perde um direito, um prazo ou sofre dano?
2. **Compromisso:** prometemos isso para uma data a alguém?
3. **Impacto:** quanto isso adianta o caso ou o escritório?
4. **Possibilidade:** dá para fazer agora, ou depende de algo que ainda não chegou?

## Exemplo: oito tarefas, capacidade para cinco

Escritório de uma pessoa, semana com cerca de 20 horas disponíveis para trabalho jurídico. Os dados são fictícios.

| # | Tarefa | Horas | Risco | Compromisso | Depende de | Decisão |
|---|---|---|---|---|---|---|
| 1 | Contestação com prazo conferido para quarta | 6 | Alto | Processual | Nada | Fazer (prioridade 1) |
| 2 | Análise de contrato prometida para sexta | 4 | Baixo | Sim, sexta | Nada | Fazer (prioridade 2) |
| 3 | Petição inicial de cobrança | 5 | Médio | Não | Notas fiscais do cliente | Não começar: documentos não chegaram. Cobrar o cliente |
| 4 | Responder três clientes sem retorno | 1 | Baixo | Sim, vencido | Nada | Fazer (prioridade 3) |
| 5 | Parecer sobre sucessão | 6 | Baixo | Sem data | Nada | Renegociar: propor entrega na semana seguinte |
| 6 | Reunião com cliente novo | 1 | Baixo | Agendada | Nada | Fazer |
| 7 | Organizar pasta de caso encerrado | 1 | Baixo | Não | Nada | Fazer se sobrar tempo |
| 8 | Manifestação sobre laudo, prazo conferido para a outra semana | 3 | Médio | Processual | Laudo já recebido | Começar sexta, se sobrar tempo |

**Total pedido:** 27 horas. **Disponível:** 20 horas.

**Por que assim.** As tarefas 1, 2, 4 e 6 somam 12 horas e têm risco ou compromisso. A 3 não pode começar porque falta documento: a ação certa é cobrar o cliente. A 5 não tem data e é grande: a ação certa é renegociar com uma data nova, avisando o cliente. Sobram 8 horas: a 8 entra porque tem prazo na semana seguinte, e a 7 só se houver folga.

# Quadro financeiro gerencial

Um olhar semanal sobre o dinheiro do escritório. Não é contabilidade: é para não esquecer de cobrar e de pagar.

{.grade}
| Item | Previsto | Recebido | Diferença | Ação |
|---|---|---|---|---|
| Honorários a receber na semana | | | | |
| Despesas do escritório a pagar | | | | |
| Despesas adiantadas por cliente (custas, diligências) | | | | |
| Cobranças a revisar | | | | |

::: atencao Dinheiro do cliente não é receita do escritório
Valores recebidos em nome do cliente (um acordo, uma indenização) ficam separados e são repassados com prestação de contas. Misturar no mesmo controle é o caminho para erro. Para registros fiscais e contábeis, siga a orientação do seu contador: este quadro não substitui isso.
:::

# Modelos em branco e preenchidos

## Checklist semanal

- [ ] Fila de exceções zerada ou com responsável
- [ ] Compromissos da próxima semana conferidos
- [ ] Comunicações recebidas transformadas em tarefa
- [ ] Painel atualizado: nenhuma tarefa sem responsável ou sem data
- [ ] Tarefas paradas há mais de duas semanas identificadas

# Desafio de quatro semanas

Antes de começar, meça o seu ponto de partida. Os números que importam são os seus: não existe referência nacional que diga qual é o "normal".

| Indicador | Semana 0 (ponto de partida) | Semana 1 | Semana 2 | Semana 3 | Semana 4 |
|---|---|---|---|---|---|
| Tarefas sem responsável | | | | | |
| Retornos a clientes vencidos | | | | | |
| Casos sem próxima ação definida | | | | | |
| Tempo real da revisão (minutos) | | | | | |

**Como medir:** na semana 0, faça a revisão completa e conte cada indicador sem corrigir nada antes. Nas semanas seguintes, conte no início da revisão.

**O que observar:** se um indicador não cai, ele aponta para uma causa (a tarefa nasce sem dono, o retorno não é marcado na agenda, a próxima ação não é escrita na hora da reunião). Anote no registro de problemas recorrentes e teste uma mudança por vez.
